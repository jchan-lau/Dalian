Connectedness as a Directed Network

Reading the spillover table as a weighted directed graph

A connectedness table is also a weighted directed network. Viewing it as a graph makes the structure of spillovers visible — and exposes why such networks need simplification.

1. The table as a graph

Treat each variable as a node and place a directed edge from to with weight — the spillover sends into . Generalized off-diagonal entries are nonnegative and are typically positive in dense empirical systems, so the result can approach a complete directed graph with directed edges. For that is edges — far too many to read directly.

Node-level summaries

The directional measures are exactly the node strengths of this graph: out-strength is the TO total (emission), in-strength is the FROM total (reception), and outin is NET. In the tool, node colour encodes NET (red transmitter, blue receiver) and node size encodes total connectedness.

2. Visual encodings and layout

Edge width and opacity scale with weight, arrowheads show direction, and a threshold hides the weakest edges. The arrangement of nodes — the layout — is a separate choice:

  • Circular. Nodes evenly on a circle — the Diebold-Yilmaz / Gabauer convention; every node visible and comparable.
  • Fruchterman-Reingold. A force model: nodes repel and the currently displayed, threshold-surviving bilateral links act as weight-scaled springs, so stronger displayed clusters pull together. Changing the threshold therefore recomputes this layout.
  • Kamada-Kawai. Places nodes so geometric distance approximates graph-theoretic distance by minimising a stress function ; often cleanest for sparse structures and trees.
Layout changes appearance, never the underlying numbers. It is a reading aid, not part of the model.

3. Why sparsify?

A complete weighted digraph holds the full information but buries the dominant structure among many weak edges. Two complementary simplifications follow: a minimum spanning tree reduces the network to its strongest links after collapsing direction; a consensus backbone keeps direction and redundancy, extracting the dominant directed hierarchy.
