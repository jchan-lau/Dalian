Minimum Spanning Trees

Distilling the network to its strongest skeleton

The minimum spanning tree (MST) is the classic way to distil a dense dependence network into its strongest skeleton, going back to Mantegna’s (1999) hierarchical analysis of stock correlations.

1. Spanning trees

Given nodes, a spanning tree is a set of edges connecting every node with no cycles. The minimum spanning tree minimises total edge weight; the maximum spanning tree maximises it. Which you want depends on whether weight means distance (minimise) or strength (maximise).

Distance vs strength. Correlation networks first map correlation to a distance, , so strongly correlated assets are close, then minimise total distance. The connectedness network already speaks in strength (spillover shares), so the tool builds a maximum spanning tree directly.

Algorithms

Kruskal’s sorts edges by weight and adds them greedily, skipping any that would close a cycle (checked with a union-find structure). Prim’s grows the tree from a seed, repeatedly adding the strongest edge to a new node. The tool uses Kruskal’s on the strength-ranked edges.

2. The directional difficulty

An MST is undirected, but the connectedness network is directed: between two markets there are two reciprocal weights, and . We must reduce each pair to one number, and the choice encodes what we care about:

ReductionWeightWhat the tree emphasises
SumTotal bilateral connectedness — overall strength, ignoring direction. Reveals co-movement clusters.
Absolute differenceNet directional asymmetry — how lopsided the link is, i.e. how strongly one market dominates.
MaximumThe dominant transmission channel — the single strongest one-way route.

3. What the MST does and does not give

The MST is sparse ( edges), connected and easy to read — an excellent first map. But it discards direction (after the reciprocal-pair reduction) and is a single tree with no alternative routes, so one strong-but-fragile edge can dominate and redundant channels are lost. Both limits motivate the consensus backbone.
