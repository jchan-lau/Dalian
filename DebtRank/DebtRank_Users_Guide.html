1 · Quick start

1
Open the tool and click Load bundled example (20 global banks) — or upload your own CSV (formats in Section 2).
2
In panel 2, keep the defaults (linear DebtRank, 1% external-asset shock on all banks) and click Run stress test.
3
Read the results in panels 3–5; optionally click Run Monte-Carlo in panel 6 for the loss distribution and VaR/CVaR.

The tool is a single HTML file: it runs entirely in your browser, needs no installation or internet connection, and your data never leave your machine.

2 · Data inputs

The tool accepts a single CSV (comma- or tab-separated) and auto-detects which of two layouts it is. Values can be in any currency unit as long as it is the same throughout (the example is in $bn).

Format A — bilateral-exposure matrix (preferred)

Use this when you know who lent how much to whom. One row per bank: first column the bank name, then one column per bank with the exposure Aij of the row bank (lender i) to the column bank (borrower j), then two final columns external_assets and equity. The first rows of the bundled example:

bankCitigroupBank of AmericaJPMorgan Chase…external_assetsequity
Citigroup0.00012.10819.702…2097.37116.58
Bank of America12.4150.00029.050…1670.8099.98
JPMorgan Chase15.34922.0710.000…1854.3391.78

Reading the first row: Citigroup has lent $12.1bn to Bank of America and $19.7bn to JPMorgan, holds $2,097bn of external (non-bank) assets, and has $116.6bn of equity. The diagonal is zero (no self-lending). The column headers between bank and external_assets must match the row names exactly and in the same order — that is how the tool recognizes this format. A zero means “no exposure”.

Format B — aggregate balance sheets

Use this when bilateral data are confidential and you only have totals. Exactly five columns:

bankinterbank_lendinginterbank_borrowingexternal_assetsequity
Citigroup102.63135.112097.37116.58
Bank of America129.20141.731670.8099.98
JPMorgan Chase145.67133.031854.3391.78

The tool reconstructs one deterministic bilateral matrix using separate lending and borrowing fitnesses, a sparse binary support, and RAS, as described in Method Description, Section 11. If system-wide lending and borrowing totals differ, borrowing is proportionally rescaled to equal lending. Re-loading the same file always gives the same network.

Caveat. Bardoscia et al. (2015) sample an ensemble of random networks. This tool deliberately keeps one reproducible topology and may add candidate links when a sparser support cannot match both RAS margins. Format-B results are a reconstruction sensitivity case, not an estimate or bound for the unknown true network.

Both example files can be downloaded from panel 1 of the tool (Download example matrix CSV / Download example aggregate CSV) and used as templates; they are also bundled as DebtRank_example_network.csv and DebtRank_example_aggregate.csv.

Validation rules

Equity must be a positive number for every bank (a bank with zero or negative equity has already failed — remove it or replace equity with a small positive value). Bilateral matrix exposures must be non-negative; negative entries are treated as zero. Aggregate lending and borrowing totals must be finite and non-negative; invalid totals are rejected. Numbers must use a dot as the decimal separator, without thousands separators.

3 · Scenario & model settings (panel 2)

ControlWhat it does & how to choose
Propagation algorithm Linear DebtRank (default): banks re-transmit every round they receive new distress — the conservative, mark-to-market-consistent estimate. Original DebtRank: each bank transmits only the first time it is hit — a lower bound. Run both to bracket the result.
Shock type External-asset shock (all banks): a market-wide scenario — every bank loses α% of its external assets. External-asset shock (selected bank): an idiosyncratic hit to one institution. Default a single bank: the Battiston (2012) thought experiment — one bank’s equity is wiped out (h=1) and the consequences are traced.
Shock size α Percent of external assets destroyed in the first round. 1% is a meaningful recession-type shock for a leveraged balance sheet; 0.1% probes near-linear behaviour; 5%+ is a severe crisis.
Include fire sales / φ Adds a simplified heuristic common-asset channel. Surviving banks sell external assets in proportion to their equity loss; φ maps aggregate sales into a fractional price drop. This is inspired by Battiston et al. (2016), but it does not solve that paper’s target-leverage restoration equation. Treat φ as a scenario parameter, not a published calibration.

4 · Walkthrough with the bundled example

The example is a synthetic but internally consistent network of 20 large global institutions circa 2008, calibrated to a stable leverage regime. Follow along:

1
Load. Click Load bundled example. The status line reports 20 institutions · 175 interbank links · spectral radius |λmax| = 0.900 with a green “stable regime” pill: shocks will be damped, not explosive — but 0.9 is close to 1, so expect strong amplification. The balance-sheet preview lets you sanity-check the data.
2
Run. Keep the defaults (linear DebtRank, external shock to all banks, α = 1%) and click Run stress test. The run converges in about 39 rounds.
3
System results (panel 3). The direct first-round loss is 16.2% of system equity, but the final global vulnerability is H(T) ≈ 70.7% — a network amplification of 4.4×, about $1,301bn of the system’s $1,839bn equity. 4 of 20 banks default (h = 1): Bank of America, JPMorgan Chase, Wells Fargo, and Bear Stearns — the four with interbank leverage above 1.2.
4
Firm results (panel 4). The impact ranking is headed by Citigroup (0.374), Barclays (0.374), RBS (0.355) and HSBC (0.346): each of their solo defaults would destroy roughly a third of everyone else’s equity. Note the two lists differ — the most dangerous banks (high impact) are not the most fragile ones (the defaulters), because impact reflects how much others have lent to you, while vulnerability reflects your own leverage. These rankings use the Battiston-style solo-default impact and current-scenario vulnerability; they do not replicate Bardoscia et al. (2015, Fig. 2).
5
Network diagram (panel 5). With the default Kamada–Kawai layout the tightly interconnected core is visible at the centre. Switch layouts (Section 6) to view the same network from different angles, and use Max exposures drawn to control clutter — it draws that many of the largest exposures (enter 0 to draw them all). The note under the chart reports how many of the total exposures are currently shown.
6
Monte-Carlo (panel 6). Click Run Monte-Carlo with the defaults (2,000 trials, mean shock 1%, 95% level). The full-propagation loss distribution sits far to the right of the first-round-only one, and VaR95 roughly quadruples once network effects are included. (Results vary slightly run to run — the draws are random.)

Your results are kept. Once you have run a scenario you can follow the links to this guide or the method description and return to the tool — the loaded data, your scenario settings and all result panels are restored automatically, so you don’t have to re-load and re-run. To start over, just load a different data set.

5 · Reading the results, panel by panel

OutputHow to read it
KPI cards (panel 3) H(T) = share of system equity destroyed; first-round loss = damage without the network; amplification = their ratio (the “network multiplier”); defaults = banks with h = 1; spectral radius = stability diagnostic (< 1 damped, > 1 explosive).
Distress propagation chart H(t) round by round. A long flat tail means slow, grinding contagion; a steep early rise means the damage is front-loaded. The gap between the first point and the plateau is the network’s contribution.
Loss decomposition bar Splits H(T) into first round (direct), second round (interbank), and the simplified heuristic third-round fire-sale scenario, if enabled. The second-round share is the headline argument for network-aware stress testing.
Impact ranking Each bank’s Battiston-style default impact: the share of other banks’ equity its solo default would destroy. This is not Bardoscia’s single-bank external-asset-shock impact measure.
Vulnerability ranking Each bank’s own loss h(T) under the scenario you ran. Red bars are defaults. Bardoscia’s Figure 2 instead averages each bank’s loss across a sequence of single-bank shock experiments.
Impact vs. vulnerability map Upper-right quadrant (above both median guides) = high impact and high vulnerability: “too central to fail”. Bubble size = total assets — note that big is not the same as dangerous.
Network diagram Node size ∝ total assets, colour ∝ DebtRank impact (blue → red), edge width ∝ exposure size. The Max exposures drawn control sets how many of the largest exposures appear (default 90; e.g. 80, 50; enter 0 to draw them all). This is purely about legibility — it never changes the underlying DebtRank or contagion results. Five layouts available (Section 6).
VaR / CVaR panel Blue histogram = first-round-only losses; red = full propagation. The rightward shift of the red VaR line versus the blue is the extra capital a network-blind risk model would fail to provide.

6 · Network-diagram layouts

The layout changes only the positions of the nodes, never the data. Each emphasizes something different:

LayoutWhat it shows best
Kamada–Kawai (default) On-screen distances approximate shortest-path distances in the network. The best general-purpose overview: central banks end up central, peripheral ones drift outward, and the core–periphery shape is immediately visible.
Spring (Fruchterman–Reingold) Linked banks attract, all banks repel. Clusters of heavily interconnected institutions pull together — useful for spotting sub-groups (e.g. a European cluster vs. a US cluster).
Circular All banks on one ring, ordered clockwise from the top by DebtRank impact. Because positions are fixed and neutral, the edges stand out — the cleanest view of who is exposed to whom, and ideal for comparing two scenarios side by side.
Shell Three concentric rings by DebtRank impact: inner ring = the most systemic ~20%, middle ring = next 30%, outer ring = the rest. A tiered watch-list as a picture.
DebtRank spiral The original Battiston et al. (2012, Fig. 3) presentation: most systemic at the centre, importance decreasing outward along a golden-angle spiral. Compact and good for ranking-focused storytelling.

The Kamada–Kawai and spring layouts are computed from the link structure (deterministically, so the picture is reproducible); circular, shell and spiral are computed from the DebtRank ranking.

7 · Preparing your own data

A practical checklist:

1
Choose the format. Bilateral exposures if you have them (supervisory returns, large-exposure data); otherwise aggregates (Format B) from published balance sheets: interbank/due-from-banks assets for lending, due-to-banks liabilities for borrowing.
2
One unit, one date. All figures in the same currency and unit, all from the same reporting date. Mixing $m and $bn is the most common silent error — the tool cannot detect it.
3
Define equity consistently. Common equity tier 1 or book equity both work; just use the same definition for every bank. Smaller equity ⇒ higher leverage matrix ⇒ more contagion, so the choice matters.
4
Check names. In Format A the column headers must repeat the row names exactly (same spelling, same order). Avoid commas inside names.
5
Sanity-check on load. The preview table should reproduce numbers you recognize; the spectral radius should typically be in the 0.3–1.2 range for a real system. A value like 8 usually signals a unit error in equity.
6
Start small. Run α = 0.1% first. In the stable regime results scale roughly linearly in α until defaults appear; the α at which the first bank defaults is itself a useful fragility statistic.

8 · Troubleshooting

SymptomCause & fix
“Could not find an ‘equity’ column.” Header misspelled or missing. The column must be named exactly equity (case-insensitive); same for external_assets, interbank_lending, interbank_borrowing.
“Equity values must be positive numbers.” A zero, negative, or non-numeric equity entry (check for thousands separators or currency symbols).
File meant as a matrix is read as “aggregate” (or errors) The matrix column headers do not match the row names exactly and in order. Fix spelling/order, or remove stray spaces.
Spectral radius implausibly large Almost always a unit mismatch: exposures in $m but equity in $bn (or vice versa).
Everything defaults at a tiny shock Not necessarily a bug: if |λmax| > 1 the system is in the unstable regime and that is the model’s message. Verify units first, then read it as a finding.
Monte-Carlo slow Cost scales with trials × banks². Reduce trials to 1,000 for exploration; use 5,000+ only for final numbers.

9 · The Python companion tool

debtrank_tool.py replicates the version03 HTML tool from the command line (same deterministic reconstruction, same CSVs, and the same stress-test calculations) and produces a multi-panel PNG report — convenient for batch runs and papers. Requirements: numpy, matplotlib.

# default run: linear DebtRank, 1% shock to all banks, Kamada-Kawai diagram
python debtrank_tool.py DebtRank_example_network.csv

# original (2012) algorithm; default of a named bank
python debtrank_tool.py data.csv --algo original --shock default --bank "Citigroup"

# fire sales on; spring layout for the network diagram
python debtrank_tool.py data.csv --fire-sales --phi 0.3 --layout spring

# network-diagram layouts: kk (default) | spring | circular | shell | spiral
python debtrank_tool.py data.csv --layout circular

# how many exposures to draw (legibility only; results are unaffected):
python debtrank_tool.py data.csv --max-edges 80         # draw 80 largest exposures (0 = all)

# Monte-Carlo VaR/CVaR; console-only report
python debtrank_tool.py data.csv --mc 2000 --mc-mean 1.0 --var-level 0.95 --no-plots

The figure is written to debtrank_report.png (override with --out). The Monte-Carlo seed is fixed by default (--seed), so Python results are exactly reproducible.
